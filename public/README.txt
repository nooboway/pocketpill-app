PocketPill Brand Assets

Files
-----
pocketpill-logo-horizontal.png
    Transparent horizontal PocketPill logo for navbar/header use.

pocketpill-icon-1024.png
    Transparent standalone PocketPill mark for app icons, social images, etc.

pocketpill-icon-512.png
    512px version of the standalone mark.

favicon.ico
    Multi-size browser favicon (16/32/48/64/128/256px).

favicon-32.png
    32px PNG favicon.

Brand colors from the supplied brand sheet
------------------------------------------
Forest Green: #0F3D34
Copper:       #C67C58
Ivory:        #FAF8F3
Charcoal:     #1F1F1F

Recommended implementation
--------------------------
Use pocketpill-logo-horizontal.png in the website navbar/header.
Use favicon.ico as the browser tab icon.

For Next.js App Router:
- Put favicon.ico in app/favicon.ico, OR use it via the metadata icons config.
- Put the logo PNG in public/brand/pocketpill-logo-horizontal.png.
- Use the standalone icon where a compact mark is required.

Important:
The supplied brand sheet was used as the source so the logo stays consistent with the approved visual identity.

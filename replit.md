# Pocket Pill Health

## Development

This project uses React 19, TanStack Start/Router, Vite, and Tailwind CSS.

Install the locked dependencies with:

```sh
bun install --frozen-lockfile
```

Run the development server with:

```sh
npm run dev -- --host 0.0.0.0 --port 5000
```

The Replit workflow is configured to run this command and serve the preview on port 5000.

## Environment

No additional external-service configuration was required to start the imported project.
